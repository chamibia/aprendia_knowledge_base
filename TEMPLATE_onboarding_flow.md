# [Project Name] — Onboarding Setup Template

## Purpose of This Template

This brief gathers what your program needs a new chatbot deployment to say and ask when a user messages it for the very first time — before they can use any course, challenge, or toolkit.

Onboarding always has 4 parts, in this order:

1. Introduction — the bot introduces itself
2. Privacy notice — the bot tells the user what happens to their messages, and asks them to agree
3. Getting-to-know-you questions — a few short questions so the bot can personalize its help
4. Pathway choice — the menu of things the user can do next

### How to Answer This Template

- Write out exactly what you want the bot to say, in the language your users will use
- Keep it short — users are reading this on a phone, often with a slow connection
- If a row doesn't apply to your project, write N/A rather than leaving it blank
- Add or remove rows in Section 3 and Section 4 — every project has a different number of questions and options
